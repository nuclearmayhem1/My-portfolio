Extended Armaments

A mod for Territory Control 2 that expands the game's arsenal with additional weapons and destructive capabilities.

Territory Control 2 comes with a system for creating weapons of varying kinds, my mod adds three different types of grenade launcher.

Additionally my mod also implements nnew weapon behaviour that enables the shell ejection effect, this was later added to the base game

Video showing test of shell ejection

The mod also contains some other bits and bobs that you can find in the source code
